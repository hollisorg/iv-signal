# IV Signal art

Six illustrations made on 2026-11-12 with ChatGPT image generation through the Codex CLI
(`~/.claude/skills/chapter-flow-site/scripts/codex-images.ps1`), using IV Studio's eye art (`iv-eye.webp`) as a style
reference only. Prompts and masters (PNG) are kept outside the repo.
Each was checked by eye for palette, subject and no lettering, then converted to WebP (quality 84) in
`src/renderer/src/assets/`.

| File | Used on |
|---|---|
| signal-hero.webp | Today, Networks, Settings headers; sidebar |
| signal-brain.webp | Brand Brain header; Today card 01 |
| signal-create.webp | Create header; Today card 02 |
| signal-approve.webp | Approve header and empty state; Today card 03 |
| signal-calendar.webp | Calendar header |
| signal-library.webp | Library header and empty state |

The icon (`build/icon.svg`) is the IV eye from IV Studio's tile with coral broadcast waves, drawn in code.
